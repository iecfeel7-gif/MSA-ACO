# Data records

The run-level archive and the manuscript-level summary are retained as separate source records. Two manuscript-level best values cannot currently be linked to retained run identifiers and are therefore not assigned to individual run records. The archived run file is provided without assigning those summary values to specific runs.

Archived MSA-ACO timing fields are blank. New executions record initialization, solver, and end-to-end times separately; no timing values are inferred for the archived records.
